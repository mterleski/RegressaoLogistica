📘 Regressão Logística - Análise com Python

Este notebook tem como objetivo aplicar o modelo de regressão logística para classificação binária utilizando Python, com foco em análise de dados e construção de modelo preditivo.

📌 Etapas abordadas:
Importação de Bibliotecas
 Bibliotecas como pandas, numpy, matplotlib, seaborn, sklearn são utilizadas para manipulação de dados, visualização e modelagem.

Carregamento e Visualização de Dados
 Leitura do dataset (parece ser relacionado a diabetes) e visualização das primeiras linhas para entender a estrutura dos dados.

Análise Exploratória dos Dados (EDA)
 Geração de gráficos, estatísticas descritivas e verificação de valores ausentes.

Pré-processamento
Normalização dos dados com StandardScaler
Separação em conjuntos de treino e teste.

Construção do Modelo de Regressão Logística
 Utilização do LogisticRegression da sklearn para treinar o modelo.

Avaliação do Modelo
Acurácia, matriz de confusão, classification report
Curva ROC e cálculo da AUC

Conclusões e Insights
 Avaliação da performance e possíveis caminhos para melhoria do modelo.

📦 Requisitos
Python 3.x
pandas, numpy, matplotlib, seaborn, sklearn
